## حلال واين 0.1.0 — نسخة تجريبية مبكرة

شغّل ألعاب وبرامج ويندوز على جهاز الماك: اسحب مجلد اللعبة إلى التطبيق واضغط **العب**. يتعرّف حلال واين على محرّك اللعبة، ويجرّب أفضل إعدادات الرسوميات، ويتأكد من أنها تعمل، ثم يتذكّرها.

### التثبيت
1. نزّل ملف **halalWine-0.1.0.dmg** من الأسفل وافتحه.
2. اسحب **حلال واين** إلى مجلد **التطبيقات**.
3. عند الفتح لأول مرة سيقول macOS إنه لا يستطيع التحقق من التطبيق، لأنه غير موقّع من Apple بعد. افتح **إعدادات النظام ← الخصوصية والأمن** واضغط **فتح على أي حال**.
4. سيثبّت معالج الإعداد Rosetta (إن لزم) وينزّل محرّك ويندوز (نحو ٣٢٠ ميغابايت، مرة واحدة فقط).

**المتطلبات:** ماك بمعالج Apple (M1 أو أحدث) ونظام macOS 15 أو أحدث.

### المزايا
- اسحب وأفلت مجلدًا أو ملف ‎.exe‎ أو برنامج تثبيت أو ملف ‎.zip‎.
- اكتشاف تلقائي لمحرّك اللعبة (Godot وUnity وUnreal وغيرها) وواجهة الرسوميات.
- يجرّب DXMT وDXVK وWineD3D بالترتيب المناسب لكل لعبة، ويدعم D3DMetal من Apple إن استوردتها.
- يثبّت Visual C++ وDirectX وXNA تلقائيًا عند الحاجة.
- واجهة عربية كاملة من اليمين إلى اليسار، مع الإنجليزية.

### حدود معروفة
- نسخة تجريبية: جُرّبت على عدد قليل من الألعاب حتى الآن.
- الألعاب التي تستخدم أنظمة مكافحة الغش (EasyAntiCheat وBattlEye وVanguard) لا تعمل.
- بعض ألعاب Steam تحتاج إلى تشغيل Steam نفسه.

إذا لم تعمل لعبة ما: **خيارات متقدمة ← إنشاء ملف تشخيص**، ثم افتح بلاغًا على GitHub وأرفق الملف.

## halalWine 0.1.0: early preview

Run Windows games and apps on your Mac. Drag a game folder in and press **Play**. halalWine detects the game's engine, tries the best graphics settings, checks the game actually starts, and remembers what works.

### Install
1. Download **halalWine-0.1.0.dmg** below and open it.
2. Drag **halalWine** to **Applications**.
3. The first time you open it, macOS says it can't verify the app, because it isn't notarized by Apple yet. Open **System Settings → Privacy & Security** and click **Open Anyway**.
4. The setup assistant installs Rosetta if needed and downloads the Windows engine. That is about 320 MB, once.

**Requires** an Apple Silicon Mac (M1 or later) with macOS 15 or later.

### What's inside
- Drag and drop a folder, a `.exe`, an installer or a `.zip`.
- Detects the game engine (Godot, Unity, Unreal and more) and its graphics API.
- Tries DXMT, DXVK and WineD3D in the right order for each game, and Apple's D3DMetal once you import it.
- Installs Visual C++, DirectX and XNA automatically when a game needs them.
- Full Arabic (right-to-left) and English interface.
- Windows engine: Wine 11.19 built from CrossOver's open-source code (via the Whisky fork), DXMT 0.80, DXVK 1.10.3 and MoltenVK. See `THIRD_PARTY_NOTICES.md`.

### Known limitations
- Early preview, tested with only a few games so far.
- Games with kernel anti-cheat (EasyAntiCheat, BattlEye, Vanguard) do not work.
- Some Steam games need the Steam client running.

If a game doesn't run, use **Advanced → Create Diagnostics File** and attach the zip to a GitHub issue.

`SHA256SUMS.txt` lists the checksum of the download.
